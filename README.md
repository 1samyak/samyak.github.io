# s-j.tech — Samyak Jain

Minimal editorial personal website built with vanilla HTML, CSS and JavaScript.

## Deploy
This repository is configured for GitHub Pages. In GitHub, open **Settings → Pages** and select **Deploy from a branch → main → / (root)**.

Custom domain: `s-j.tech`.

## Files
- `index.html` — site structure and content
- `styles.css` — responsive editorial design system
- `script.js` — progressive enhancement
- `favicon.svg` — monogram favicon

## Update
Edit the content in `index.html`. Replace the placeholder email and verify social profile URLs before publishing.
